# Авторские тексты — фронтенд

Лабораторная работа №5 по теме «Расчёт лексического разнообразия авторских текстов».
Отдельный репозиторий React-приложения. Ветка лабораторной — `lab5-author_texts-react`.

Стек: React 19, TypeScript 5, Vite 7, React Router 7, React-Bootstrap 2 и Bootstrap 5.
В ЛР-5 приложение работает для гостя с локальными mock-данными без запросов к API.
Redux и собственный Context не используются.

## Запуск

Требуется Node.js 22.12+ и npm.

```powershell
npm ci
npm run dev
```

Адрес: `http://127.0.0.1:5173/author_texts`.
Бэкенд, Docker, PostgreSQL, Redis и MinIO для запуска ЛР-5 не требуются.

```powershell
npm test
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт сборку в `dist/`.
Для размещения приложения на сервере нужен SPA fallback на `index.html`.

## Четыре страницы приложения

| Страница | Поля и содержимое | Кнопки и действия | Доступность в ЛР-5 |
|---|---|---|---|
| Корпус авторских текстов | Слайдер минимальной длины; карточки в два столбца с обложкой, названием, количеством всех и уникальных токенов и лайков | «Применить», «Сбросить»; нажатие на карточку открывает её в ленте | Доступна гостю |
| Лента авторских текстов | Видео, название, краткое описание, количество всех и уникальных токенов и лайков | «Следующий» открывает следующую карточку текущей выборки; после последней открывается первая | Доступна гостю; лайки только отображаются |
| Добавление авторского текста | Фото, видео, название, краткое описание, количество всех и уникальных токенов | «Далее» создаёт черновик; «Опубликовать» публикует заполненную карточку | Пункт меню отключён; форма и действия предусмотрены для ЛР-6 после входа |
| Вход | Имя пользователя и пароль | «Войти», «Зарегистрироваться» | Пункт меню отключён; форма и действия предусмотрены для ЛР-6 |

Нижняя панель содержит четыре пункта: «Лента», «Добавление», «Корпус», «Вход».
По заданию ЛР-5 доступны только «Лента» и «Корпус». Описание двух остальных страниц
задаёт их поля и действия для следующего этапа; их формы пока не реализованы.

Адрес корпуса — `/author_texts`. Адрес ленты — `/author_texts/feed` для первой
карточки выборки и `/author_texts/feed/:author_text_id` для выбранной карточки.
Оба адреса ленты используют один компонент страницы.

## Фильтрация и переходы

Слайдер сразу показывает выбранное число. Фильтрация выполняется по полю
`text_length` после нажатия «Применить»: остаются карточки с количеством токенов
не меньше указанного. «Сбросить» возвращает все карточки.

Выбранная и применённая границы хранятся в `AuthorTextsApp` через `useState`
и передаются через props. При переходах между корпусом и лентой фильтр сохраняется;
после перезагрузки страницы сбрасывается. Кнопка «Следующий» перебирает только
отфильтрованные карточки. Неизвестный ID и пустая выборка обрабатываются на странице.

## Mock-данные и локальные медиа

`src/modules/author_texts_mock.ts` содержит шесть карточек. Поля соответствуют
схеме ответа API предыдущих лабораторных: ID, название, описание, адреса фото
и видео, количества токенов, TTR, количество лайков, `is_owner` и `is_liked`.
Числовые значения демонстрационные; анализ исходных текстов в ЛР-5 не выполняется.

Изображения и видео импортируются из `src/assets/media/` и включаются в сборку.
Файлы по умолчанию находятся в `public/media/author_texts_default.jpg` и
`public/media/author_texts_default.webm`. При пустом адресе или ошибке загрузки
компоненты подставляют резервный файл. Если не загружается и резервное видео,
остаётся обложка. У карточки «Отцы и дети» адреса медиа намеренно не заполнены.

## Компоненты и хуки

| Компонент | Назначение и props |
|---|---|
| `AuthorTextsApp` | Состояния фильтра, маршруты и отфильтрованный массив |
| `AuthorTextsCorpus` | Получает карточки, границы фильтра, максимум и обработчики действий |
| `AuthorTextsFilter` | Получает `value`, `maximum`, `onChange`, `onApply`, `onReset`; отображает форму фильтра |
| `AuthorTextsCard` | Получает объект карточки через `text` и создаёт ссылку на ленту |
| `AuthorTextsFeed` | Получает выборку через `texts`, выбирает карточку по ID из URL |
| `AuthorTextsImage`, `AuthorTextsVideo` | Получают источники медиа и название; обрабатывают ошибки загрузки |
| `AuthorTextsNavigation` | Получает `firstId` для перехода к первой карточке выборки |

`useState` хранит состояния фильтра и ошибочных адресов медиа. `useEffect`
в `useAuthorTextsTitle` меняет заголовок вкладки и восстанавливает предыдущий
при очистке. `useParams` читает ID карточки, `useLocation` определяет текущую
страницу и активный пункт меню.

Точка входа — `src/author_texts_main.tsx`. Стили приложения —
`src/author_texts_styles.css`: розовый фон `#FCE7F3`, белые карточки,
серые скруглённые кнопки `#3F3F46`. Видео заполняет область ленты через
`object-fit: cover`.

Тесты проверяют фильтрацию, переходы, прямые адреса, пустую выборку,
резервные медиа, ограничения гостя и отсутствие запросов к API.
